Projects

OpenStreetMap Graz - Java

Java • Spring Boot • gRPC • OpenStreetMap

A map and routing application developed as part of the Object-Oriented Programming II teamwork course at TU Graz. The application processes OpenStreetMap data for Graz to represent roads, land use areas, and amenities, and provides functionality for querying map features and calculating shortest routes between locations.

Rentaroo - Python

Python • Pytest • Flast • MongoDB

A team project I did as a part of the course Agile Software Development at TU Graz. Rentaroo is a peer-to-peer tool rental web application where users can list tools, request rentals, manage availability, and review tools and lenders. I worked as both a developer and tester, writing a large part of the project's automated test suite using pytest and gaining hands-on experience with testing Flask applications

Radioactive Decay Simulator - Python

Python • NumPy • Matplotlib • JSON

A Monte Carlo simulation of radioactive decay using real isotope data and half-lives. The program simulates individual decay events using probabilistic sampling and compares the simulated results with the theoretical decay curve using Matplotlib. Currently supports several isotopes, including U-238, Th-234, and Pa-234. I am working on expanding the project to simulate full decay chains and plan to add a GUI for visualizing isotope information.
